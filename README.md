# Jiahao Liang's Academic Homepage

Website: [https://jh-aliang.github.io/](https://jh-aliang.github.io/)

Based on the [AcadHomepage template by RayeRen](https://github.com/RayeRen/acad-homepage).

GitHub Actions extracts the static website from `site.zip` and publishes it to GitHub Pages. To update the website, replace `site.zip` with the latest website bundle and push to `main`; deployment runs automatically.
